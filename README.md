# FORMULA-1-Race-Intelligence-Dashboard-Analysis-Report-2010-2026-


## Project Overview
A Formula 1 data analytics project built with Tableau Public to explore driver performance, constructor performance, race participation, driver nationality, podium achievements, and race completion patterns.

The project uses a dashboard and a guided story to support descriptive comparison across seasons. It is an educational analytics project, not an official Formula 1 performance system.

## Objectives
- Compare driver and constructor points.
- Explore driver DNFs and race completion patterns.
- Review race participation by season.
- Explore driver nationality and Grand Prix rounds by host country.
- Compare constructor points across seasons.
- Summarize podium achievements by driver and team.
- Publish the dashboard and story through Tableau Public.

## Dataset
Source repository: https://github.com/muharsyad/formula-one-datasets

The project uses relevant Formula 1 tables such as race results, races, drivers, and circuits where available in the connected data source. Confirm the exact tables and any relationships in the final Tableau workbook.

**Data limitation:** The dataset used for this project did not provide the tyre-compound fields required for a reliable tyre strategy analysis. No tyre-compound conclusions are claimed.
